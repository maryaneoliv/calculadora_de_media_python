### Como instalar e Executar
Para instalar e executar o arquivo, primeiro é necessário instalar o Python no computador. Depois, abra o terminal ou prompt de comando e navegue até a pasta onde está o arquivo .py. Para executar o programa, digite python nome_do_arquivo.py e pressione Enter. Se o comando não funcionar, tente python3 nome_do_arquivo.py. Assim, o Python irá interpretar o código e executar o programa.
***

### Exemplo de Uso ou Demonstração
*CÓDIGO:*<br>
def calcular_media (nota1, nota2):<br>
    return(nota1 + nota2) /2<br>
print ("=== Sistema de Notas do Aluno ===")<br>
n1 = float(input ("Digite a primeira nota: "))<br>
n2 = float(input ("Digite a segunda nota: "))<br>
media = calcular_media(n1, n2)<br>
print(f"A média final é: {media:.2f}")<br>
if media >= 7.0:<br>
    print("Status: APROVADO!")<br>
else:<br>
    print("Status: REPROVADO.")<br>

*EXECUÇÃO:*
<br>
Digite a primeira nota: 10<br>
Digite a segunda nota: 9<br>
A média final é: 9.50<br>
Status: APROVADO!<br>
